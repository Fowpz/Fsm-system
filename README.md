# Fsm-system - Система управления выездными специалистами

## Концепция и проблема

Система предназначена для компаний, предоставляющих выездные ремонтные и сервисные услуги, и их клиентов. Она решает проблему потери заявок, сложного поиска исполнителей и неудобного распределения заказов между специалистами. Все процессы объединяются на одной платформе.

## Основной функционал

- Регистрацию пользователей и компаний с разделением ролей.
- Каталог компаний с рейтингами и отзывами.
- Создание и обработку заявок клиентов.
- Назначение специалистов на заявки.
- Управление расписанием и контроль пересечений.
- Отслеживание статусов и истории заявок.
- Уведомления пользователей.
- Формирование отчётов и оставление отзывов.
